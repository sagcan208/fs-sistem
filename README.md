# fs-sistem

This repository demonstrates a minimal filesystem project. It is useful for testing or learning how to interact with a basic directory structure.

## Prerequisites

- Git to clone the repository
- A POSIX-compliant shell such as `bash`

## Running the script

An example script named `hello.sh` is included. After cloning the repository, make sure it is executable and run it from the project directory:

```bash
./hello.sh
```

## Example usage

Running the command above prints:

```bash
Hello from fs-sistem
```
